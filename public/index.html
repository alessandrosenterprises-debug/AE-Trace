Start the Expo preview

In a terminal, run:

cd D:\aetrace\rider-app
npm start

Scan the Metro QR code with Expo Go on an Android phone. On iPhone, scan it with the Camera app and open in Expo Go.

02

Connect the app to AE-Trace

Enter your deployed HTTPS app URL or your computer's LAN URL in the rider app. Enroll the rider's phone using a single-use code from the admin panel.

i
Expo Go is for foreground preview

Expo Go can preview rider enrollment and location sharing while the app is open. Background location requires a standalone development build and platform permissions; it is not provided by Expo Go.
